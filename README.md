# 박성재 · Park Seongjae

기획·디자인·개발·배포·운영을 처음부터 끝까지 직접 합니다.
단가로(Dangaro)는 가입·결제·CRM 운영 데이터를 직접 보면서 흐름을 개선해 왔고,
Desktop Dday는 사용자 피드백을 모아 기능을 다듬은 끝에 매각까지 마쳤습니다.
화면을 그리는 데서 끝나지 않고, 실제 사용자 흐름과 운영 데이터로 제품을 키우는 데 익숙합니다.

## 일하는 방식

- **처음부터 끝까지 직접**: 기획·UX·디자인·구현·배포·운영을 한 사람이 책임지는 1인 개발 흐름에 익숙합니다.
- **운영 데이터로 다듬기**: 가입·결제·CRM 같은 실제 사용자 흐름을 직접 대시보드로 보면서 제품을 개선합니다.
- **사용자 피드백 반영**: 출시 후 들어오는 리뷰·문의·로그를 모아 다음 기능과 정책에 반영합니다.
- **실시간 상태가 중요한 UI**: WebSocket/Socket.io, 재연결, presence, 읽음·타이핑, optimistic UX.
- **운영자가 매일 쓰는 도구**: 권한, 정책 제어, 로그, 엑셀/CSV 내보내기, 개인정보 마스킹.
- **AI-assisted workflow**: Claude Code, Codex, Gemini를 코드 리뷰·리팩터링·테스트 보강에 연결.
